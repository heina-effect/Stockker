# Intraday Chart Reopen Checklist

당일(Intraday) 분봉 차트 기능(`NEXT_PUBLIC_ENABLE_INTRADAY_CHART`)을 다시 활성화하기 전에 충족해야 하는 품질 보증 및 아키텍처 점검 목록입니다.

## 1. 데이터 집계 및 정합성 (Data Integrity)
- [ ] **10분봉 Backfill 신뢰성**: KIS API(`FHKST03010200`)에서 가져온 틱 데이터가 정확하게 10분 단위로 병합(aggregate)되고 있는지 검증.
- [ ] **오름차순 정렬**: KIS에서 제공하는 내림차순(최신순) 데이터를 차트 렌더링 직전에 반드시 오름차순(시간순)으로 뒤집는 로직이 누락 없이 적용되어 있는지 확인.
- [ ] **빈 버킷 및 null 처리**: 장중 거래가 없는 시간대(빈 버킷)의 시/고/저/종가(OHLC)를 이전 종가 기준으로 올바르게 Carry-forward(이월) 하는지 검증.

## 2. 시간대 및 세션 경계 (Session Boundaries)
- [ ] **정규장 시간 제어**: 현재 `08:00 ~ 20:00` 그리드를 사용하고 있으나, KIS 데이터 중 시간외 거래(Pre-market, After-market) 데이터가 정규장(09:00 ~ 15:30) 차트에 노이즈를 발생시키지 않는지 확인.
- [ ] **미래 구간 대응**: 현재 시각이 11:00일 경우, 11:00 이후의 시간대(미래 구간)에 대해 차트가 빈 공간을 올바르게 유지하고 불필요한 라인을 그리지 않는지 확인.

## 3. Rate-Limit 및 성능 (Performance Safety)
- [ ] **초기 마운트 Fan-out 억제**: 상세 페이지 마운트 시 `daily`와 `intraday` 요청이 동시에 KIS로 향하지 않도록(의도적인 지연 로딩 또는 탭 클릭 시점 호출 등) 설계 변경이 이루어졌는지 검증.
- [ ] **Cache 히트**: Intraday 백필 데이터가 짧은 TTL 동안 메모리에 캐싱되어 중복 컴포넌트 렌더링 시 KIS REST가 두 번 이상 호출되지 않는지 검증 (`EGW00201` 에러 방지).

## 4. UI 및 UX
- [ ] **Scale (Y축) 붕괴 방지**: 비정상적인 폴백(Fallback)이나 0원 데이터가 유입될 때 Scaling Guard가 정상 작동하여 Y축 스케일이 무너지지 않는지 확인.
- [ ] **MA 선 표시**: MA5, MA20 선이 10분봉 캔들과 매끄럽게 연결되는지 테스트.
