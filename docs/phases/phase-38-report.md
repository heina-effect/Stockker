# Phase 38 Report — 종목 일봉/주봉 페이지네이션 (120봉 정배열 복구)

## 완료 요약

오버나이트 스크리닝에서 분석 대상 종목 대부분이 "120봉 부족"으로 탈락하여 `normal`/`aggressive` 버킷이 항상 비던 근본 원인을 해소했다. Phase 37에서 거시필터 **지수**에만 적용했던 페이지네이션을, **종목 일봉/주봉**에도 동일하게 적용해 120일·120주 정배열 판정에 필요한 데이터를 확보한다. 중복을 피하기 위해 지수/일봉/주봉의 페이지네이션을 **공통 헬퍼 `fetchPaginatedCandles()`로 통일**했다.

---

## 문제 (debug 실측)

- 스크리닝 분석 종목 16개 중 13개가 "이평선 계산을 위한 시세 데이터(120봉) 부족"으로 탈락 → `normal`/`aggressive` 0개.
- 종목이 기준 미달이 아니라, KIS가 단일 호출당 봉을 충분히 안 줘서 **MA120 계산 자체가 불가능**한 상태였다.
- 측정값: 주식 일봉/주봉(`FHKST03010100`)은 단일 호출 약 100봉. 특히 주봉은 120주(약 2.5년)를 한 번에 확보 불가. (Phase 37에서 지수만 페이지네이션, 종목 일/주봉은 누락)

---

## 주요 변경 사항

### 1. 페이지네이션 공통 헬퍼 추출 (`rest-client.ts`)
- Phase 37의 지수 페이지네이션 로직을 **`fetchPaginatedCandles()`** 공통 헬퍼로 추출하고, 지수/일봉/주봉이 모두 이를 사용하도록 리팩터링(중복 3벌 → 1벌).
- 동작: 날짜 창을 과거로 옮겨가며 목표 130봉 누적, `stck_bsop_date` 중복 제거 후 최신순 정렬. 페이지가 `EGW00201`로 막히면 1.2s 백오프 후 1회 재시도, 그래도 실패 시 확보분으로 Graceful Break(첫 페이지 실패만 에러 전파).

### 2. 종목 일봉/주봉 페이지네이션 적용
- `getDomesticStockDaily()` — window 150일, 최대 3페이지(≈ 100거래일/페이지 → 130봉 확보).
- `getDomesticStockWeekly()` — window 760일, 최대 3페이지(≈ 108주/페이지 → 130주≈2.5년 확보).
- `getDomesticIndexDaily()` — 공통 헬퍼 사용으로 전환(동작 동일, window 90일/최대 4페이지).

### 3. 하루 단위 캐시 (지수와 동일)
- 캐시 키에 KST 날짜 포함(`daily_{symbol}_{YYYYMMDD}`, `weekly_{symbol}_{YYYYMMDD}`), TTL 26h.
- 종목당 거래일 1회만 신규 조회하고, 당일 2차 호출부터는 캐시 적중으로 즉시 응답.

### 4. rate limit 보호 유지
- 모든 페이지 호출은 `callKisApi` → 단일 통합 큐(`globalKisRequestQueue`, 350ms) 경유. 수동 setTimeout으로 큐를 우회하지 않음.

### 5. 호출량 대응 — 분석 대상 12 → 8 (`route.ts`)
- 일/주봉 페이지네이션으로 종목당 호출이 늘어(상세 1 + 일봉 ~2 + 주봉 ~2 = 최대 5호출) cold-start 부하가 커지므로, 분석 대상을 `MAX_TARGET_STOCKS = 8`로 제한.
- `primaryCandidates`가 많은 날에도 상한을 넘지 않도록 `slice(0, 8)` 후 채우도록 cap 명확화(기존엔 후보가 많으면 12를 초과해 분석될 수 있었음).

### 6. 후보 선정: 거래대금순 → 회전율(vol_tnrt) 우선 (`route.ts`)
- **문제**: 페이지네이션으로 정배열 판정은 정상화됐으나, 분석 8종목이 거래대금 상위순이라 대부분 대형주(삼성전자/SK하이닉스 등)였다. 대형주는 회전율 5%를 구조적으로 못 넘겨 정석/공격형이 거의 안 나왔다(실제 통과한 제주반도체/HPSP는 중소형주).
- **수정**: 1차 후보 필터(등락률 +3% 이상 + 거래대금 10억 이상)는 유지하되, **정렬을 거래대금순 → 회전율(`vol_tnrt`) 높은 순으로 변경**해 상위 8종목을 선정. 8개 미만일 때 채우는 fillPool도 회전율 높은 순으로 정렬.
- volume-rank의 `vol_tnrt`는 **정렬 우선순위로만** 사용한다. 최종 5% 회전율 PASS/FAIL은 기존대로 2차 현재가 상세의 `detail.vol_tnrt`로 판정(Phase 36 가드 유지).

### 7. 후보 필터 정제 + 안내 분리 + 노이즈 정리 (`route.ts`)
- **분석 전 "그냥 폐기" 필터 (pureStocks)**: 후보/결과/안내 어디에도 넣지 않고 조용히 제외해 분석 슬롯도 차지하지 않게 한다.
  - 가격제한폭 초과 등락률(`prdy_ctrt` < -30% 또는 > +30%): 감자/병합/거래재개 등 비정상 이벤트
  - 동전주: 현재가(`stck_prpr`) 1,000원 미만(가격 누락=0 포함)
  - ETF/ETN/스팩(기존 유지). 거래정지/정리매매는 volume-rank에서 판별 불가하므로 기존대로 2차 상세에서 배제.
- **fill 단계 하락종목 가드**: 후보 부족 시 채우는 fillPool에 등락률 음수 제외 가드 추가(폐기 조건은 pureStocks에서 이미 적용됨).
- **신규상장 등 "정상이나 분석 불가" → `excludedNotice` 분리**: 위험/기준 문제는 없는데 이력 부족(120봉 미만)으로 정배열 판정만 불가한 종목은 `results.exclude`가 아니라 별도 응답 필드 `excludedNotice`로 분리한다. `{ symbol, name, reason: "상장 이력 짧음 — 데이터 부족으로 정배열 판정 불가" }`. (위험 플래그가 같이 있으면 그대로 `exclude`로 분류)
- **`results.exclude` 노이즈 정리**: 분석 대상(8) 밖이라 분석하지 않은 종목은 더 이상 `exclude`에 넣지 않는다(`"분석 대상 외 미분석"` 라벨 제거). 대신 카운트만 집계해 디버그 응답 `diagnostics.outOfScopeCount`로 노출. `results.exclude`에는 **"분석 후 기준 미달"(정배열/회전율/거래량/위험필터)만** 남는다.

> 보안(디버그 응답 `stack` 제거 + `sanitizeError` 마스킹)은 직전 커밋(`overnight 디버그 응답 보안 정제`)에서 적용 완료. 본 작업에서도 유지됨을 재검증.

## 검증 결과

```
# cold-start (토큰 캐시 삭제 후 첫 호출)
elapsed: 16s
{ "ok": true, "kosdaq": 968.4, "normal": 0, "aggressive": 2, "exclude": 14 }
"120봉 부족" 사유: 13건 → 1건

# aggressive 분류 (일봉+주봉 120봉 정배열 통과 — 페이지네이션 없이는 불가능)
080220 제주반도체 / 403870 HPSP

# 2차 호출 (캐시 warm)
elapsed: 0s
```

- **페이지네이션 정상 작동**: 종목이 120봉 정배열을 통과해 `aggressive`에 분류됨(이전엔 항상 0/0).
- **"120봉 부족" 13 → 1**: 남은 1건(`014950` 삼익제약)은 투자주의 + 역배열로 어차피 제외되는 종목이며, 상장/거래 이력이 짧아 주봉 120주 미만으로 추정(결과에 영향 없음).
- **캐시 효과 확인**: cold 16s → warm 0s.
- `npm run validate` 통과(0 errors, 0 warnings), `npx tsc --noEmit` 통과.

- 대형주 독점 해소 — 분석 대상이 고회전 중소형 테마주 위주로 전환됨.
- `aggressive` 2 → 3, "회전율 기준 미달" 탈락 감소(애초에 고회전 종목을 우선 선정).

### 필터 정제 + 안내 분리 적용 후 (섹션 7)

```
{ "results": { "normal": 0, "aggressive": 3, "exclude": 5 },
  "excludedNotice": [], "diagnostics": { "outOfScopeCount": 6 } }
# results.exclude 사유 — 전부 "분석 후 기준 미달"만 남음
삼익제약: 투자주의 / 정배열 미달 ...
LG전자:  회전율 미달(2.06%) / 정배열 미달 / 거래량 미달
SK스퀘어: 회전율 미달(1.07%) / 거래량 미달
```

- **비정상(±30% 초과)·동전주(<1,000원) 노출 0건** (results/notice 어디에도 없음).
- `results.exclude`에 "분석 대상 외 미분석" 노이즈 사라짐 — `outOfScopeCount`(6)로만 집계.
- `excludedNotice`는 이번 실행에선 비어 있음(후보 중 위험 플래그 없는 단기이력 종목 없음). 유일한 단기이력 종목 삼익제약은 투자주의 플래그가 있어 의도대로 `exclude`로 분류됨 — 분리 로직 정상.
- 응답 어디에도 `stack`/키 문자열 노출 0건 재확인.

## 보존한 가드레일 (Non-Negotiables)

- **120일 정배열 기준 무변경**: MA120 정배열 알고리즘은 그대로 두고, 판정에 필요한 데이터만 페이지네이션으로 공급.
- **rate limit 보호**: 단일 통합 큐 유지, 큐 우회 없음.
- **인트라데이 숨김 / 단일 fetch 홈 / disclaimer** 등 기존 동결 항목 유지.

---

## 참고 (후속 검토)

- 일봉/주봉을 하루 단위 캐시로 전환하면서, 이 함수를 공유하는 일봉 차트의 "오늘 캔들"이 장중 갱신되지 않고 다음 거래일에 반영된다. 비실시간 리서치 제품 정책과 일치하나, 차트만 더 자주 갱신이 필요하면 차트 전용 경로 분리를 검토한다.
