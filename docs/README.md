# Stockker Docs

문서는 성격별로 폴더를 나눠 관리합니다.

## 폴더 구조

| 폴더 | 용도 |
| --- | --- |
| `core/` | 현재 런타임 기준의 핵심 설계, 설정, API 계약, 데이터/테마/저장 정책 |
| `phases/` | Phase별 감사 문서와 완료 리포트, 제품 전환 기록 |
| `release/` | 베타 릴리즈 체크리스트, 알려진 이슈, 동결 규칙, 인트라데이 재개 조건 |
| `ops/` | 운영 플레이북, 관찰성, KIS 설정 감사 |
| `ui/` | UI 검증 노트와 shadcn 관련 보조 정보 |
